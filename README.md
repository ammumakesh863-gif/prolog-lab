MEDICAL DIAGNOSIS EXPERT SYSTEM

PROJECT DESCRIPTION

A rule-based Medical Diagnosis Expert System developed using GNU Prolog.

The system asks the user about different symptoms and identifies possible medical conditions based on symptom matching.

TECHNOLOGIES USED

- Prolog
- GNU Prolog

DISEASES COVERED

- Influenza
- Common Cold
- Migraine
- Gastroenteritis

FEATURES

- Interactive yes/no symptom input
- Rule-based diagnosis
- Symptom matching
- Displays possible conditions
- Shows matching symptom count

HOW TO RUN

Open GNU Prolog and load the project:

['project.pl'].

Then run:

start.

DISCLAIMER

This project is an educational expert-system demonstration and is not a substitute for professional medical diagnosis.
